WarehouseAPI1
=============

Ett webbprogram för lagerhantering.

Projektinformation
------------------
- Projektnamn: WarehouseAPI1
- Version: 1.0-SNAPSHOT
- Java-version: 17
- Byggverktyg: Maven

Tekniker som används
----------------
- Jakarta EE 10
- Jakarta CDI
- Jakarta EJB
- Jakarta RESTful Web Services (JAX-RS)
- Jakarta Persistence (JPA)
- Jakarta Validation
- Jakarta Security
- Jakarta Servlet
- JUnit 5 för tester

Projektstruktur
----------------
- src/ - Källkodsmapp
- target/ - Byggmapp
- pom.xml - Maven-konfiguration

Bygga projektet
-------------------
För att bygga projektet, kör:
```
mvn clean install
mvn clean package
```

Köra projektet
------------------
Detta är ett WAR-program som kan köras på en Jakarta EE-kompatibel server.

Beroenden
-----------
Alla beroenden hanteras genom Maven och finns i pom.xml-filen.
